# Weather App 🌤️

A responsive web application that displays current weather information and a 5-day forecast for any city using the OpenWeather API.

## Features
- Current weather details (temperature, condition, icon).
- 5-day weather forecast.
- Colorful and interactive design.
- Error handling for invalid city names.
- Refresh button to reload weather data.
